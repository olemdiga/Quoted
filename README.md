# 📚 Quoted

**Online:** 29 Nov 2025

A digital library of wisdom. Organized by topic for the analytical mind. Depth over sentiment. Structure over noise.

## About

Quoted is a structured collection of insights across philosophy, psychology, systems thinking, and the architecture of human behavior. Each topic page contains quotes selected for coherence, not popularity. The collection builds a layered understanding of fundamental concepts through curated juxtaposition.

## Purpose

- **Curate** quotes that survive scrutiny. No platitudes. No empty inspiration.
- **Organize** knowledge by topic to surface connections across domains.
- **Provide** a distraction-free reading environment. The content is the interface.

## Structure

The library is organized into thematic pages.

| Category | Example Topics |
| :--- | :--- |
| Philosophy & Mindset | `absurdism`, `existentialism`, `stoicism`, `nihilism` |
| Psychology & Behavior | `beliefs`, `fear`, `cognitive-dissonance`, `habits` |
| Systems & Thinking | `algorithms`, `complexity`, `emergence`, `rationality` |
| Personal Development | `discipline`, `consistency`, `skill-development` |
| Life & Relationships | `authenticity`, `friends`, `fatherhood`, `community` |

## Features

- Mobile-first, responsive layout.
- Minimalist interface. No tracking. No analytics. No comments.
- Fast load times. Static HTML/CSS/JS only.
- Topic navigation via sidebar.
- Key insights highlighted within each category.

## Technology

- HTML, CSS, JavaScript.
- Google Fonts: Orbitron, Exo 2, Share Tech Mono.
- No frameworks. No build step. No external dependencies.

## Use

1. Select a topic from the sidebar.
2. Read the curated quotes.
3. Note connections across topics.
4. Integrate or ignore. The library is a tool, not a prescription.

## Contributing

This is a personal curation project. Suggestions are reviewed against a single criterion: **Does the quote add structural insight or elegant articulation to the existing topic?** Submissions failing this test will be declined without comment.
